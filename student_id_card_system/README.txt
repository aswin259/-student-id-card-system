# Student ID Card System

A simple, responsive student ID card generator built with HTML, CSS and JavaScript.

## How to run
1. Extract `student_id_card_system.zip`.
2. Open the extracted folder.
3. Double-click `index.html` (or open it in Chrome/Edge).
4. Enter student details and optionally upload a photo.
5. Click **Generate ID Card**.
6. Use **Print / Save as PDF** to print or save the card as a PDF.

## Features
- Student name, register number, department, year and blood group
- College name and academic year
- Student photo upload with live preview
- Print-friendly ID card layout
- Optional PNG image export (needs internet for the html2canvas CDN)
- Works locally in a modern browser; no server or database required

## Customization
Edit `index.html` to change labels/default college name and `style.css` to customize the design.
